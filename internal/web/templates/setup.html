What this wizard does

Each step is the real form — creating the profile, saving API credentials, choosing where the secret comes from, running the phone login, binding a channel, creating the filesystem, and starting the first mount all happen right here. State (done / skipped) is derived from the filesystem on every load, so refreshing always shows the current truth; the same operations remain available on their dedicated pages for later changes.
